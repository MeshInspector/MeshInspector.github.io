Finds the rigid transformation of source points to target points from given matches, many of which can be wrong: tests the transformations through random samples of three matches and keeps the one with most inliers, then refines it by least squares fitting on all its inliers.

Parameters
matches(source point, target point) pairs, e.g. from findFPFHMatches(...)
Returns
rigid transformation of source points to target points, or error if there are less than three matches, no consistent sample was found or progress returned false Generated from function MR::findRigidXfRansac. Parameter srcPoints can not be null. It is a single object. Parameter tgtPoints can not be null. It is a single object. Parameter matches can not be null. It is a single object. Parameter params can not be null. It is a single object. Parameter progress is a single object. Parameter progress has a default argument: {}, pass a null pointer to use it. Never returns null. Returns an instance allocated on the heap! Must call MR_expected_MR_AffineXf3f_std_string_Destroy() to free it when you're done using it.
