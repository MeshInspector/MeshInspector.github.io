Finds the transformations registering given objects (meshes or point clouds with normals) as one or several groups without any initial alignment: each pair of objects is aligned by matching FPFH descriptors of their samples (see computeFPFH), finding the rigid transformation by findRigidXfRansac with overlap scoring and refining it by ICP; then the objects are linked by a spanning tree of the pairs with the largest overlap (at least params.minOverlap) Generated from function MR::globalRegistration. Parameter objects can not be null. It is a single object. Parameter params is a single object. Parameter params has a default argument: {}, pass a null pointer to use it. Parameter progress is a single object. Parameter progress has a default argument: {}, pass a null pointer to use it. Never returns null. Returns an instance allocated on the heap! Must call MR_expected_MR_GlobalRegistrationResult_std_string_Destroy() to free it when you're done using it.
