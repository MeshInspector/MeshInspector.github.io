typedef struct MR_ComputePointsToDistanceVolume MR_ComputePointsToDistanceVolume

CPU implementation of IComputePointsToDistanceVolume, used by pointsToMeshFusion when no other one is given; prefer its lazy computeFunctionVolume over compute, which materializes the whole volume in memory Generated from class MR::ComputePointsToDistanceVolume. Base classes: Direct: (non-virtual) MR::IComputePointsToDistanceFunctionVolume Indirect: (non-virtual) MR::IComputePointsToDistanceVolume Supported MR_PassBy modes: MR_PassBy_DefaultConstruct, MR_PassBy_Copy, MR_PassBy_Move (and MR_PassBy_DefaultArgument and MR_PassBy_NoObject if supported by the callee).
