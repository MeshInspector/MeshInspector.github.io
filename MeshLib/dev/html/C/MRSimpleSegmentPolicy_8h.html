◆ MR_SimpleSegmentPolicy

typedef struct MR_SimpleSegmentPolicy MR_SimpleSegmentPolicy

simple policy for MeshSegmenter, which prefers merging smaller by area segments, with long common boundary, and with low average curvature metric on it Generated from class MR::SimpleSegmentPolicy. Supported MR_PassBy modes: MR_PassBy_Copy, MR_PassBy_Move (and MR_PassBy_DefaultArgument and MR_PassBy_NoObject if supported by the callee).
