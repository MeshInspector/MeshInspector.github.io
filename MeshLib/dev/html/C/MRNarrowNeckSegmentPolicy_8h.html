◆ MR_NarrowNeckSegmentPolicy

typedef struct MR_NarrowNeckSegmentPolicy MR_NarrowNeckSegmentPolicy

policy for MeshSegmenter with the same preferences as in SimpleSegmentPolicy, which additionally prohibits merging of two segments over a narrow neck: a short common boundary, when one of the segments has longer boundary with mesh holes; it keeps the parts weakly attached to the main surface (e.g. scanning artifacts) as separate segments Generated from class MR::NarrowNeckSegmentPolicy. Supported MR_PassBy modes: MR_PassBy_Copy, MR_PassBy_Move (and MR_PassBy_DefaultArgument and MR_PassBy_NoObject if supported by the callee).
