◆ MR_fitBSplineSurfaceToMesh()

MRC_API MR_expected_MR_FittedBSplineSurface_std_string * MR_fitBSplineSurfaceToMesh ( const MR_MeshPart * mp,
const MR_FitBSplineSurfaceToMeshSettings * settings,
const MR_std_function_bool_from_float * progress )

approximates a mesh part with disk topology by a bicubic B-spline surface passing near its vertices: the vertices are parametrized by leastSquaresConformalMap rotated to its bounding rectangle of the smallest area with u along the longer side (the triangles of the part are counterclockwise in the parameters, so the normals of the surface and of the part agree), then several times the surface is fitted by fitBSplineSurface and the vertices are projected on it to improve their parameters; additional points with small weights are taken inside the triangles much larger than the typical one; the grid of the returned surface is built, and its maxError is the maximum distance from the vertices of the part; if the part is not one disk (several components, or touching itself in a vertex) then the parametrization can be meaningless, and a surface with large maxError is returned, so pass a disk or check maxError;

Returns
an error if the part cannot be parametrized, has fewer than 35 vertices (too few for 6x4 control points), the margin is wrong, no fit succeeds, or the operation is canceled via the callback, which gets the progress in one step per tried number of control points Generated from function MR::fitBSplineSurfaceToMesh. Parameter mp can not be null. It is a single object. Parameter settings is a single object. Parameter settings has a default argument: {}, pass a null pointer to use it. Parameter progress is a single object. Parameter progress has a default argument: {}, pass a null pointer to use it. Never returns null. Returns an instance allocated on the heap! Must call MR_expected_MR_FittedBSplineSurface_std_string_Destroy() to free it when you're done using it.
