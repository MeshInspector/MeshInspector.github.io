◆ MR_convertRasterToImage()

MRC_API MR_expected_MR_Image_std_string * MR_convertRasterToImage ( const MR_Raster * raster)

converts a raster with one layer to an image (the rows are reordered from bottom to top):

  • the values of one channel are scaled from the range of finite values to gray colors, NaN and infinite values become black;
  • three or more channels are RGB or RGBA colors (the channels after the fourth are ignored): integer values keep their high byte and are taken as unsigned ones, floating-point values are clamped to [0, 1], NaN becomes 0 Generated from function MR::convertRasterToImage. Parameter raster can not be null. It is a single object. Never returns null. Returns an instance allocated on the heap! Must call MR_expected_MR_Image_std_string_Destroy() to free it when you're done using it.
