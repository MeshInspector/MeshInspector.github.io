Detailed Description

Wraps a pointer to a single shared reference-counted heap-allocated const MR::Mesh.

Generated from class std::shared_ptr<const MR::Mesh>. Heap-allocated instances are held in Owned<std_shared_ptr_const_MR_Mesh>.

◆ use_count()

auto meshlib::std_shared_ptr_const_MR_Mesh::use_count ( ) const -> core::ffi::c_int

How many shared pointers share the managed object. Zero if no object is being managed. This being zero usually conincides with MR_std_shared_ptr_const_MR_Mesh_get() returning null, but is ultimately orthogonal. Note that in multithreaded environments, the only safe way to use this number is comparing it with zero. Positive values might change by the time you get to use them.

Calls MR_std_shared_ptr_const_MR_Mesh_use_count().
