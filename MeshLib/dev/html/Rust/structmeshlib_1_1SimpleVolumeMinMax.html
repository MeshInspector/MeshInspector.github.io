Detailed Description

represents a box in 3D space subdivided on voxels stored in T; and stores minimum and maximum values among all valid voxels Generated from class MR::SimpleVolumeMinMax. Base classes: Direct: (non-virtual) MR::SimpleVolume MR::Box1f
