Detailed Description

Special data type for MR::cutMesh: the intersections of all contours in one array, one contour after another.

This is special data for MR::cutMesh, you can convert some other contours representation to it by:
MR::surfaceLineToClosedMeshContour MR::surfacePathsToMeshContours
