Detailed Description

A class for searching for outliers of points

The class caches the prepared search results, which allows to speed up the repeat search (while use same radius) Generated from class MR::OutliersDetector.

Generated from class MR::OutliersDetector. Heap-allocated instances are held in Owned<OutliersDetector>.
