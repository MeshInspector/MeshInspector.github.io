Detailed Description

the class is responsible for finding shortest edge paths on a mesh in Euclidean metric using A* heuristics Generated from class MR::EdgePathsAStarBuilder. Base classes: Direct: (non-virtual) MR::EdgePathsBuilderT<MR::MetricToAStarPenalty>
