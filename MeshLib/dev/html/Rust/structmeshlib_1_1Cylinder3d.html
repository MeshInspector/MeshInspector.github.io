Detailed Description

A class describing a cylinder as a mathematical object. A cylinder is represented by a centerline, a radius, and a length. TODO: Cylinder3 could be infinite. For example for infinite Cylinder3 we could use negative length or length = -1 Generated from class MR::Cylinder3d.

Generated from class MR::Cylinder3d. Heap-allocated instances are held in Owned<Cylinder3d>.
