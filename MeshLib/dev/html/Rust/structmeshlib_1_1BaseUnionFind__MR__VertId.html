auto meshlib::BaseUnionFind_MR_VertId::unite_unbalanced ( first:meshlib::VertId ,
second:meshlib::VertId  ) -> meshlib::Owned< meshlib::std_pair_MR_VertId_bool >

unites the two sets containing given elements WITHOUT balancing by set size (BaseUnionFind keeps no sizes): it simply attaches one set's root under the other's, so chained calls can build taller trees. Prefer UnionFind::unite, which selects the new root by set size, when many unions follow one another.

Returns
first: new common root, second: true if the union was done (false if already in one set) Generated from method MR::BaseUnionFind<MR::VertId>::uniteUnbalanced.
