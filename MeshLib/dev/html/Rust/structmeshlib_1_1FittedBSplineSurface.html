Detailed Description

B-spline surface fitted to some points, with the points of the surface in a regular grid of its parameters, which allow projecting on the surface without initial parameters Generated from class MR::FittedBSplineSurface.

Generated from class MR::FittedBSplineSurface. Heap-allocated instances are held in Owned<FittedBSplineSurface>.
