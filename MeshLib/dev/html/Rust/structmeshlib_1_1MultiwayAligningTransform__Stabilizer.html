Detailed Description

small stabilizer allows one to convert the linear system from under-determined to determined (e.g. too few linearly independent pairs for some object); large stabilizer results in suboptimal found transformations (huge stabilizier => zero transforamtions) Generated from class MR::MultiwayAligningTransform::Stabilizer.
