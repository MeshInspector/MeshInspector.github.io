Detailed Description

This object type renders label in scene

default pivot point = (0, 0) Generated from class MR::ObjectLabel. Base classes: Direct: (non-virtual) MR::VisualObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object

Generated from class MR::ObjectLabel. Heap-allocated instances are held in Owned<ObjectLabel>.
