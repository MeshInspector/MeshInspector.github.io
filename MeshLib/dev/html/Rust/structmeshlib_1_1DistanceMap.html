Detailed Description

this class allows to store distances from the plane in particular pixels validVerts keeps only pixels with mesh-intersecting rays from them Generated from class MR::DistanceMap. Base classes: Direct: (non-virtual) MR::RectIndexer

Generated from class MR::DistanceMap. Heap-allocated instances are held in Owned<DistanceMap>.
