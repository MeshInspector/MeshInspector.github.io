Detailed Description

Stores a pair of points: one samples on the source and the closest to it on the target Generated from class MR::PointPair. Base classes: Direct: (non-virtual) MR::ICPPairData

Generated from class MR::PointPair. Heap-allocated instances are held in Owned<PointPair>.
