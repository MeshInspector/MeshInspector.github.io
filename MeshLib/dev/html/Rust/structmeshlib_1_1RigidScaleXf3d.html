Detailed Description

rigid (with scale) transformation that multiplies all distances on same scale: y = s*A*x + b, where s is a scalar, A is rotation matrix 3x3 stored as 3 angles, and b is shift vector Generated from class MR::RigidScaleXf3d.

Generated from class MR::RigidScaleXf3d. Heap-allocated instances are held in Owned<RigidScaleXf3d>.
