◆ adjust_collapse()

auto meshlib::DecimateSettings::adjust_collapse ( ) const -> &meshlib::std_function_void_from_MR_UndirectedEdgeId_float_ref_MR_Vector3f_ref

The user can provide this optional callback for adjusting error introduced by this edge collapse and the collapse position.

On input the callback gets the squared error and position computed by standard means, and callback can modify any of them. The larger the error, the later this edge will be collapsed. This callback can be called from many threads in parallel and must be thread-safe. This callback can be called many times for each edge before real collapsing, and it is important to make the same adjustment.

Returns a pointer to a member variable of class MR::DecimateSettings named adjustCollapse.

Calls MR_DecimateSettings_Get_adjustCollapse(). The reference to this object might be preserved as the return value.

◆ set_adjust_collapse()

void meshlib::DecimateSettings::set_adjust_collapse ( value:&meshlib::std_function_void_from_MR_UndirectedEdgeId_float_ref_MR_Vector3f_ref )

The user can provide this optional callback for adjusting error introduced by this edge collapse and the collapse position.

On input the callback gets the squared error and position computed by standard means, and callback can modify any of them. The larger the error, the later this edge will be collapsed. This callback can be called from many threads in parallel and must be thread-safe. This callback can be called many times for each edge before real collapsing, and it is important to make the same adjustment.

Modifies a member variable of class MR::DecimateSettings named adjustCollapse.

Calls MR_DecimateSettings_Set_adjustCollapse(). The reference to the parameter value might be preserved in this object in element adjustCollapse.
