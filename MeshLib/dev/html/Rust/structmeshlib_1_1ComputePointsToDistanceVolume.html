Detailed Description

CPU implementation of IComputePointsToDistanceVolume, used by pointsToMeshFusion when no other one is given; prefer its lazy computeFunctionVolume over compute, which materializes the whole volume in memory Generated from class MR::ComputePointsToDistanceVolume. Base classes: Direct: (non-virtual) MR::IComputePointsToDistanceFunctionVolume Indirect: (non-virtual) MR::IComputePointsToDistanceVolume
