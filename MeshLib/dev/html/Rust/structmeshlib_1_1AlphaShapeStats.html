Detailed Description

the amount of work done during the search of alpha-shape triangles; every function below only increases the counters, never resets them, so the statistics of several calls can be accumulated in one object Generated from class MR::AlphaShapeStats.

Generated from class MR::AlphaShapeStats. Heap-allocated instances are held in Owned<AlphaShapeStats>.
