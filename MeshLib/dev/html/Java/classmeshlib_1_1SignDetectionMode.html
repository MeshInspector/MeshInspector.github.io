Detailed Description

how to determine the sign of distances from a mesh

The constants are static fields of this class. value holds the underlying value, so this can also hold values that aren't named constants.

◆ OddCrossings

final SignDetectionMode meshlib.SignDetectionMode.OddCrossings = new SignDetectionMode(3)
static

a point is inside if the surface is crossed an odd number of times on the way from the point to infinity, triangle orientation is ignored (as InsideMeshRule.OddCrossings in makeInsideMeshVolume); for meshes with holes, the result depends on the ray direction (+X); signedDistanceToMesh casts a ray from every point, while the volume functions (e.g. meshToDistanceVolume) cast one ray per row of voxels, which is much faster; this mode does NOT have CUDA acceleration at this moment
