Detailed Description

represents a box in 3D space subdivided on voxels stored in T; and stores minimum and maximum values among all valid voxels Generated from class MR::SimpleVolumeMinMaxU16. Base classes: Direct: (non-virtual) MR::SimpleVolumeU16 MR::Box<unsigned short>

Instances created here own their C++ objects, see CppObject.
