◆ renderUi()

void meshlib.IRenderObject.renderUi ( meshlib.UiRenderParams params)

Render the UI. This is repeated for each viewport. Here you can either render immediately, or insert a task into params.tasks, which get Z-sorted.

  • params will remain alive as long as the tasks are used.
  • You'll have at most one living task at a time, so you can write a non-owning pointer to an internal task. Generated from method MR::IRenderObject::renderUi.

Calls MR_IRenderObject_renderUi().
