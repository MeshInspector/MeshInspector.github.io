◆ forceFill()

boolean meshlib.CutMeshParameters.forceFill ( )

This flag defines the MR::cutMesh behaviour in case bad faces occur: basically MR::cutMesh removes all faces which contours pass through, adds new edges to topology and fills all removed parts. If bad faces occur, nothing is filled unless this flag is set; then bad faces are filled too, but their triangulation can be bad (may have self-intersections or tunnels)

Note
Bad faces here mean faces where contours have intersections and cannot be cut and filled in a good way Returns a pointer to a member variable of class MR::CutMeshParameters named forceFill. The reference to this object might be preserved as the return value.

Calls MR_CutMeshParameters_Get_forceFill().
