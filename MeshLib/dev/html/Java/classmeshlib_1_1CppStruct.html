Detailed Description

The base class of the wrappers of the C++ structs exposed with --expose-as-struct.

An instance is a view over a memory segment holding the struct. Instances created in Java own their memory (freed by the garbage collector), those returned by reference from the bindings point into memory owned by something else, which they keep alive.
