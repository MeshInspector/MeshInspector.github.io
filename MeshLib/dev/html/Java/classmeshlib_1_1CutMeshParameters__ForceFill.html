Detailed Description

This enum defines the MR::cutMesh behaviour in case bad faces occur: basically MR::cutMesh removes all faces which contours pass through, adds new edges to topology and fills all removed parts

Note
Bad faces here mean faces where contours have intersections and cannot be cut and filled in a good way

The constants are static fields of this class. value holds the underlying value, so this can also hold values that aren't named constants.
