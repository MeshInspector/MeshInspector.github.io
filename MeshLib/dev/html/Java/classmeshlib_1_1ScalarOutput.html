Detailed Description

The base class of int_output, float_output, ... (named after the C type, like in the Python bindings), which the wrappers take for the mutable scalar parameters: int & needs exactly one element, int * accepts null, one element, or an array. An instance owns length() scalars in native memory (freed by the garbage collector), which the C++ functions read and write.
