Detailed Description

the buffers makeDeloneEdgeFlips grows on every call; a caller running it many times on small meshes (e.g. one hole patch after another) keeps one instance between the calls to allocate them just once; one cache must not be used by several threads at once Generated from class MR::DeloneFlipsCache.

Instances created here own their C++ objects, see CppObject.
