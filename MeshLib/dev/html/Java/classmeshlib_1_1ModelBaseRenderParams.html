Detailed Description

Common rendering parameters for meshes (both for primary rendering and for the picker; the picker uses this as is while the primary rendering adds more fields). Generated from class MR::ModelBaseRenderParams. Base classes: Direct: (non-virtual) MR::BaseRenderParams Derived classes: Direct: (non-virtual) MR::ModelRenderParams
