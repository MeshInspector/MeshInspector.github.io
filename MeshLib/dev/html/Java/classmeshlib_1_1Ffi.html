◆ lookup()

synchronized java.lang.foreign.SymbolLookup meshlib.Ffi.lookup ( java.lang.String group)
static

The symbols of the library of a file group. The library is loaded on the first use from the libraries bundled in the jar (see bundledLibrary()), else from java.library.path (on Windows with LOAD_WITH_ALTERED_SEARCH_PATH, so its dependencies are found next to it before anything else: the directory of java.exe comes first in the default search order, and it has DLLs like freetype.dll that can shadow the real ones). If that fails, it's loaded with System.loadLibrary(), and then by its platform-specific file name through the system loader.
