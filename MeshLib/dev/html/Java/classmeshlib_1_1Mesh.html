Detailed Description

This class represents a mesh, including topology (connectivity) information and point coordinates, as well as some caches to accelerate search algorithms Generated from class MR::Mesh.

Instances created here own their C++ objects, see CppObject.

◆ calcFastWindingNumber()

float meshlib.Mesh.calcFastWindingNumber ( meshlib.Vector3f pt,
java.lang.Float beta )

computes generalized winding number in a point (pt), which is

  • for closed mesh with normals outside: 1 inside, 0 outside;
  • for planar mesh: 0.5 inside, -0.5 outside; and in general is equal to (portion of solid angle where inside part of mesh is observable) minus (portion of solid angle where outside part of mesh is observable)
    Parameters
    betadetermines the precision of fast approximation: the more the better, recommended value 2 or more Generated from method MR::Mesh::calcFastWindingNumber.
