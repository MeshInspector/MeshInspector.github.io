Detailed Description

represents a box in 3D space subdivided on voxels stored in T; and stores minimum and maximum values among all valid voxels Generated from class MR::VdbVolume. Base classes: Direct: (non-virtual) MR::VoxelsVolume<MR::FloatGrid> MR::Box1f

Instances created here own their C++ objects, see CppObject.
