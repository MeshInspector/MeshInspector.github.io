Detailed Description

in the most general form, geodesic path can start in any mesh location (MeshTriPoint), then pass triangles along straight lines, making turns on edges (MeshEdgePoint), and finish in any mesh location (MeshTriPoint) Generated from class MR::GeodesicPath.
