meshlib.Raster meshlib.rasterload.Functions.fromTiff ( java.lang.String path,
meshlib.RasterLoadSettings settings,
meshlib.rasterload.TiffLoadSettings tiffSettings )
static

loads the first image of a .tiff file as a raster with one layer:

  • gray, palette and RGB images keep the stored samples of any type (gray values, color indices or color components) as channels;
  • libtiff decodes the other formats (gray with alpha, YCbCr, CMYK, less than 8 bits per sample, etc.) to four UInt8 channels of RGBA colors, which are not multiplied by alpha unless the file stores them so (associated alpha);
  • the formats that libtiff cannot decode are read as stored too if each pixel has one sample or three or more interleaved samples of 8 to 64 bits, otherwise loading fails;
  • the files compressed by the methods that libtiff does not support fail to load;
  • the rows keep the stored order whatever the Orientation tag says, also in the decoded formats Generated from function MR::RasterLoad::fromTiff.

Calls MR_RasterLoad_fromTiff(). The C++ function returns expected<MR::Raster, std::string>: the value is returned and an error is thrown as UnexpectedResultException.
