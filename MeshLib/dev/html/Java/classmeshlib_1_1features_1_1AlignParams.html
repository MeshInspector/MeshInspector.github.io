◆ locators()

meshlib.std_vector_MR_Features_AlignPair meshlib.features.AlignParams.locators ( )

Their centers are matched in the least squares sense by the motion the primary pair leaves free: spin about the primary direction and, for planes, translation along them. For a point primary, the first locator sets the direction to spin about. A locator's lever arm (its distance from the primary axis, or for planes from the locator centroid) should be well above its fitting noise, otherwise the noise sets the spin. Returns a pointer to a member variable of class MR::Features::AlignParams named locators. The reference to this object might be preserved as the return value.

Calls MR_Features_AlignParams_Get_locators().
