Detailed Description

a point cloud and a ball radius prepared for the search of alpha-shape triangles; the emptiness of a ball is tested in integer coordinates with simulation-of-simplicity resolving the degeneracies, so both the cloud and the radius are needed in integer form as well Generated from class MR::AlphaShapeData.

Instances created here own their C++ objects, see CppObject.
