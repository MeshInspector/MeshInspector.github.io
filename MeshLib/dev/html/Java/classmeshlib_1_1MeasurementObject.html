Detailed Description

A common base class for measurement objects. Can't be constructed directly. Generated from class MR::MeasurementObject. Base classes: Direct: (non-virtual) MR::VisualObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object Derived classes: Direct: (non-virtual) MR::AngleMeasurementObject MR::DistanceMeasurementObject MR::PointMeasurementObject MR::RadiusMeasurementObject

Instances created here own their C++ objects, see CppObject.
