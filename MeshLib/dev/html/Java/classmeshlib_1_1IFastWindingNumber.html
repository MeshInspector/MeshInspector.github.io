Detailed Description

Abstract class for fast approximate computation of generalized winding number for a mesh (using its AABB tree) Generated from class MR::IFastWindingNumber. Derived classes: Direct: (non-virtual) MR::Cuda::FastWindingNumber MR::FastWindingNumber
