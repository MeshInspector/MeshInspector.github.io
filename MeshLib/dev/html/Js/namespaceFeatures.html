◆ MeasureResult_Status

enum Features::MeasureResult_Status

A C++ enum: the constants are numbers, so this also holds values that aren't named constants.

Enumerator
ok 
notImplemented 

Algorithms set this if this when something isn't yet implemented.

badFeaturePair 

Algorithms set this when the calculation doesn't make sense for those object types. This result can be based on object parameters, but not on their relative location.

badRelativeLocation 

Can't be computed because of how the objects are located relative to each other.

notFinite 

The result was not finite. This is set automatically if you return non-finite values, but you can also set this manually.

◆ align()

AffineXf3d Features::align ( Features::AlignPair primary,
Features::AlignParams params )

Returns the rigid transformation in world space that moves the moving features onto the fixed ones. The primary pair is matched exactly: planes are seated against each other, axes (line, circle, cylinder, cone) become coaxial with coinciding centers, points (point, sphere) coincide; see AlignParams for the rest. Generated from function MR::Features::align.

Calls MR_Features_align(). params defaults to {}.
