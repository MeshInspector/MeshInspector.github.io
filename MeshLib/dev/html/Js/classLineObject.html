Detailed Description

Object to show plane feature Generated from class MR::LineObject. Base classes: Direct: (non-virtual) MR::FeatureObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
