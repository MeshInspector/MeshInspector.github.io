Detailed Description

policy for MeshSegmenter with the same preferences as in SimpleSegmentPolicy, which additionally prohibits merging of two segments over a narrow neck: a short common boundary, when one of the segments has longer boundary with mesh holes; it keeps the parts weakly attached to the main surface (e.g. scanning artifacts) as separate segments Generated from class MR::NarrowNeckSegmentPolicy.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
