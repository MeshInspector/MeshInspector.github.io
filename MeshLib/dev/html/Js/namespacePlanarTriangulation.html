std_optional_MR_HoleFillPlan PlanarTriangulation::getMonotonePlan ( Mesh mesh,
std_vector_std_vector_MR_EdgeId loops,
Vector3f normal )

splits the near-planar region bounded by loops in monotone parts, without triangulating them this is the sweep-line triangulation stopped right after monotonation

Parameters
loopsone closed EdgeLoop per boundary of one region, bounding holes of mesh as trackRightBoundaryLoop returns them (a slit of one edge is a loop of 2 edges, and a loop of one edge is skipped); which way round a loop runs does not matter; the holes can be several parts of one region split by edges between them, as all the holes of a face cut along contours (the parts between the contours that cross its sides, and both sides of every island), since an edge taken both ways adds zero winding
normalthe orientation the region is monotone around, see triangulateDisjointContours
Returns
std::nullopt if the loops intersect or a chord would land in a face instead of a hole, so that the caller can fall back on filling every loop separately; otherwise a plan with numTris == 0 for executeHoleFillPlan, which then only adds edges (empty if already monotone, a no-op). Validate it with isFillingMultipleEdgeFree, since a chord may duplicate an off-loop mesh edge

std_vector_std_vector_MR_EdgeId loops,
Vector3f normal,
WholeEdgeMap outPatchMap,
PlanarTriangulation::ISweepLineCache cache )

triangulate hole boundary loops of mesh in the mesh's own 3d space, orienting faces around normal combinatorics run on the dominant-axis projection of normal; output vertices keep the exact mesh coordinates (no projection round-trip), and loops sharing a mesh vertex are merged by identity.

Parameters
loopsone closed EdgeLoop per contour (as produced by trackRightBoundaryLoop on each hole edge)
outPatchMapoptional output: for each patch boundary edge (by undirected id) the mesh edge it copies, directed along it; edges past its size are the triangulation's own
Returns
std::nullopt if the loops self-intersect, otherwise the patch mesh
