Detailed Description

B-spline surface fitted to some points, with the points of the surface in a regular grid of its parameters, which allow projecting on the surface without initial parameters Generated from class MR::FittedBSplineSurface.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.

◆ project()

Vector2d FittedBSplineSurface::project ( Vector3d p)

parameters of the surface point closest to given one: BSplineSurface::project starting from the closest point of the grid; requires buildGrid() to be called after the last change of the surface; the result is a local minimum of the distance, which can be not the closest point if the surface is strongly curved (e.g. nearly closed, where also the extensions of the fitted part come close to each other), or if the grid is sparse in space relative to the curvature (the grid is regular in the parameters, not in space) Generated from method MR::FittedBSplineSurface::project.
