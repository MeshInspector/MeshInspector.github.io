Detailed Description

an object that stores a points Generated from class MR::ObjectPointsHolder. Base classes: Direct: (non-virtual) MR::VisualObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object Derived classes: Direct: (non-virtual) MR::ObjectPoints

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
