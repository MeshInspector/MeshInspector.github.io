Detailed Description

an object that stores a mesh Generated from class MR::ObjectMesh. Base classes: Direct: (non-virtual) MR::ObjectMeshHolder Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
