Detailed Description

an object that stores a points Generated from class MR::ObjectPoints. Base classes: Direct: (non-virtual) MR::ObjectPointsHolder Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
