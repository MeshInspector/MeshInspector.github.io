Detailed Description

A class describing a cylinder as a mathematical object. A cylinder is represented by a centerline, a radius, and a length. TODO: Cylinder3 could be infinite. For example for infinite Cylinder3 we could use negative length or length = -1 Generated from class MR::Cylinder3f.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
