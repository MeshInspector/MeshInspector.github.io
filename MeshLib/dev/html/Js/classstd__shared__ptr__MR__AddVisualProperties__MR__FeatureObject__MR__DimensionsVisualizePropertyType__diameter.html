Detailed Description

Wraps a pointer to a single shared reference-counted heap-allocated MR::AddVisualProperties<MR::FeatureObject, MR::DimensionsVisualizePropertyType::diameter>.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
