Detailed Description

an object that stores a mesh Generated from class MR::ObjectMeshHolder. Base classes: Direct: (non-virtual) MR::VisualObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object Derived classes: Direct: (non-virtual) MR::ObjectDistanceMap MR::ObjectMesh MR::ObjectVoxels

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
