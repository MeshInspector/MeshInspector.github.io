Detailed Description

Represents a radius measurement. Generated from class MR::RadiusMeasurementObject. Base classes: Direct: (non-virtual) MR::MeasurementObject Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
