Detailed Description

stores index of some element, it is made as template class to avoid mixing faces, edges and vertices Generated from class MR::UndirectedEdgeId. Derived classes: Direct: (non-virtual) MR::NoDefInit<MR::UndirectedEdgeId>

Has the same layout as the C++ struct, the fields are accessed in place in wasm memory. new X(ffi.RAW, pointer, owned, owner) wraps existing memory.
