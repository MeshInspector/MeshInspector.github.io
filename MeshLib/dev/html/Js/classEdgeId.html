Detailed Description

Those are full specializations in MRId.h, so MR_CANONICAL_TYPEDEFS doesn't work on them. Have to add this too. Generated from class MR::EdgeId. Derived classes: Direct: (non-virtual) MR::NoDefInit<MR::EdgeId>

Has the same layout as the C++ struct, the fields are accessed in place in wasm memory. new X(ffi.RAW, pointer, owned, owner) wraps existing memory.
