Detailed Description

simple policy for MeshSegmenter, which prefers merging smaller by area segments, with long common boundary, and with low average curvature metric on it Generated from class MR::SimpleSegmentPolicy.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
