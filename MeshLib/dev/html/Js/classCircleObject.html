Detailed Description

Object to show sphere feature, position and radius are controlled by xf Generated from class MR::CircleObject. Base classes: Direct: (non-virtual) MR::AddVisualProperties<MR::FeatureObject, MR::DimensionsVisualizePropertyType::diameter> Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject MR::FeatureObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
