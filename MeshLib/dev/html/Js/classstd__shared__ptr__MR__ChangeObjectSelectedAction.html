number std_shared_ptr_MR_ChangeObjectSelectedAction::use_count ( )

How many shared pointers share the managed object. Zero if no object is being managed. This being zero usually conincides with MR_std_shared_ptr_MR_ChangeObjectSelectedAction_get() returning null, but is ultimately orthogonal.
