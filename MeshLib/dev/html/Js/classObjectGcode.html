Detailed Description

an object that stores a g-code Generated from class MR::ObjectGcode. Base classes: Direct: (non-virtual) MR::ObjectLinesHolder Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
