Detailed Description

Wraps a pointer to a single shared reference-counted heap-allocated MR::ChangePointCloudPointsAction.

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.

number std_shared_ptr_MR_ChangePointCloudPointsAction::use_count ( )

How many shared pointers share the managed object. Zero if no object is being managed. This being zero usually conincides with MR_std_shared_ptr_MR_ChangePointCloudPointsAction_get() returning null, but is ultimately orthogonal. Note that in multithreaded environments, the only safe way to use this number is comparing it with zero. Positive values might change by the time you get to use them.
