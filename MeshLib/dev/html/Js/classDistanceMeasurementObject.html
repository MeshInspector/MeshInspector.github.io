Represents a distance measurement. Generated from class MR::DistanceMeasurementObject. Base classes: Direct: (non-virtual) MR::MeasurementObject MR::ObjectComparableWithReference Indirect: (non-virtual) MR::ObjectChildrenHolder MR::Object MR::VisualObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
