Detailed Description

A base class for a data-model object that is a feature/measurement that can be compared between two models. Generated from class MR::ObjectComparableWithReference. Derived classes: Direct: (non-virtual) MR::DistanceMeasurementObject MR::PointMeasurementObject

Instances created here own their C++ objects, see CppObject. new X(ffi.RAW, pointer, owned, owner) wraps an existing object.
