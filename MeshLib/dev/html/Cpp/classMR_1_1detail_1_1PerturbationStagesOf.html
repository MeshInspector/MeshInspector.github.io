Detailed Description

template<int N, bool Bounded>
class MR::detail::PerturbationStagesOf< N, Bounded >

segmentIntersectionTriPlaneOrder: it reaches the polynomial path with all three largest ids in the plane

the points of a predicate with the degrees of their perturbation, which moves them in stages: at stage s = 1, ..., numStages() only the points with the s smallest ids are perturbed (orient3dPoly leaves the others unperturbed); a polynomial of the predicate that is not zero at stage s already has the leading term of the full one, since every term with a point of a later stage has a larger degree than every term without; and if it was zero at stage s - 1, its terms without the points of stage s cancel one another, so only the products of the terms of degrees from place( s ) up remain (see from in lowestTermOfSumOfProducts); at most N points; if Bounded, the degrees need not fit in int64, and the stages end before the first one whose terms can have degrees above it (see getPointDegrees), so that firstStage gives the empty value if no stage before gives one
