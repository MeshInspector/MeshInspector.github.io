Detailed Description

no version of the function with rvalue-referenced meshes, because meshes' copies are currently used for sorting intersections

a mesh of the boolean and its contours of intersection with the other mesh before the cut, with the boolean's data for an exact cut; the contours can include lone ones (inside one face, crossing none of its edges), which cutMesh connects exactly only given the boolean's sorting data, see sortData
