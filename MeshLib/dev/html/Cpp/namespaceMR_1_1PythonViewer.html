Detailed Description

The API of the mrviewerpy Python module, generated from this header over the C bindings (scripts/mrbind/generate.mk). The calls wait for the viewer's GUI thread, so the module releases the GIL around every call (--release-gil).

◆ launch()

void MR::PythonViewer::launch ( const ViewerLaunchParams & params = {},
const ViewerSetup & setup = {} )

Starts the viewer with the given params and setup, and returns once it is up and accepts calls. On Windows and Linux the window opens here, and the script keeps running alongside it. On macOS the viewer runs on the calling thread, which must be the main one: the window opens in showViewer(), or at the interactive prompt, where it stays live while the interpreter waits for input, in input() too. Raises RuntimeError if the viewer could not start (no display, or already launched once in this process).

◆ showViewer()

void MR::PythonViewer::showViewer ( )

Keeps the window open until the user closes it or shutdown() is called from another thread. On macOS the window opens here, so this call is required there; make it from the main thread. After it returns the viewer is closed for good, and further viewer calls raise RuntimeError.
