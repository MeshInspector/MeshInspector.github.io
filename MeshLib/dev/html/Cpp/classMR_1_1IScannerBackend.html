Detailed Description

A scanner SDK backend of the Scanner tool, without ImGui/MRViewer dependencies; the host and the generic UI use only this. Called on the GUI thread; per-frame getters must not block; nothing touches the delay-loaded SDK before loadRuntime(). Failures are English text (literals marked _t) in the returned Expected. How to write, register and install one: https://meshlib.io/documentation/ScannerBackendGuide.html
