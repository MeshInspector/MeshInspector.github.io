Detailed Description

template<typename Policy>
class MR::MeshSegmenter< Policy >

starting from individual faces, merges them in progressively larger segments in the order of increasing merge penalty, until every connected component contains only 1 segment or all remaining merges are prohibited

Template Parameters
Policymust have (see SimpleSegmentPolicy as an example):
  • type SegmentData, data of one segment; a += b must make from the data of two segments the data of their union;
  • type SegmentBdData, data of the common boundary of two segments; a += b must make from the data of two boundary parts the data of their union;
  • SegmentData segmentFromTri( FaceId ) const, returns the data of a single-triangle segment;
  • SegmentBdData bdFromEdge( UndirectedEdgeId ) const, returns the data of an edge having triangles from both sides;
  • double mergePenalty( const SegmentData& a, const SegmentData& b, const SegmentBdData& bd ) const (or static), returns the penalty of merging the segments (a) and (b) with the common boundary (bd), or prohibitMergePenalty to forbid the merge
