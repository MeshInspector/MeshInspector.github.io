MR_BIND_IGNORE Expected< Mesh > MR::WeightedShell::meshShell ( const Mesh & mesh,
const ParametersMetric & params )
nodiscard

consider a mesh where each vertex has additive weight, and this weight is linearly interpolated in mesh triangles, and the distance to a point is considered equal to (euclidean distance - weight), constructs iso-surface of such distance field corresponding to params.offset value using marching cubes MR_BIND_IGNORE to hide this function in Python API because calling Python's Lambda will be extremely slow anyway
