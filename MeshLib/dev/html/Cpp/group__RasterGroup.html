◆ convertRasterToFloats() [1/2]

MR_BIND_IGNORE Expected< void > MR::convertRasterToFloats ( const Raster & raster,
float * dst,
size_t size )

#include <MRMesh/MRRaster.h>

converts the values of a raster to floats in dst, which has room for size = dims.x * dims.y * dims.z values, in the order of the raster:

  • one channel is taken as is;
  • three or more channels give the luma 0.299 R + 0.587 G + 0.114 B of the first three; fails for two channels, an unknown type, data whose size does not match the dimensions, or another size

◆ convertRasterToImage()

Expected< Image > MR::convertRasterToImage ( const Raster & raster)

#include <MRMesh/MRRaster.h>

converts a raster with one layer to an image (the rows are reordered from bottom to top):

  • the values of one channel are scaled from the range of finite values to gray colors, NaN and infinite values become black;
  • three or more channels are RGB or RGBA colors (the channels after the fourth are ignored): integer values keep their high byte and are taken as unsigned ones, floating-point values are clamped to [0, 1], NaN becomes 0
  • Generated by 1.14.0
