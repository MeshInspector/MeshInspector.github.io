Detailed Description

stores map from element id in[0, size) to T;

provides two operations: 1) change the value of any element; 2) find the element with the largest value Generated from class MR::Heap&lt;double, MR.GraphEdgeId, std::greater&lt;double&gt;&gt;. This is the non-const half of the class.
