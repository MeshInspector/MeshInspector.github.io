Detailed Description

Members:

  PackedMesh : the mesh is already packed optimally (e.g. by mesh.packOptimally()), and the parts are ranges of face ids

  AABBTree : the parts are subtrees of mesh's AABB tree (taken from the mesh if present, otherwise constructed), no packing is needed;
the number of parts is rounded up to a power of two
