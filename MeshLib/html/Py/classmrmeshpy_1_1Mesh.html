Detailed Description

Generated from:  MR::Mesh
Aliases:  std_shared_ptr_Mesh, std_shared_ptr_const_Mesh

This class represents a mesh, including topology (connectivity) information and point coordinates,
as well as some caches to accelerate search algorithms

split given edge on two parts:
dest(returned-edge) = org(e) - newly created vertex,
org(returned-edge) = org(e-before-split),
dest(e) = dest(e-before-split)
\\details left and right faces of given edge if valid are also subdivided on two parts each;
the split edge will keep both face IDs and their degrees, and the new edge will have new face IDs and new faces are triangular;
if left or right faces of the original edge were in the region, then include new parts of these faces in the region
\\param new2Old receive mapping from newly appeared triangle to its original triangle (part to full)

◆ updateCachesAfterSplits()

None mrmeshpy.Mesh.updateCachesAfterSplits ( self,
Const_phmap_flat_hash_map_Id_FaceTag_Id_FaceTag_phmap_Hash_Id_FaceTag_phmap_EqualTo_Id_FaceTag_Allocator_std_pair_Id_FaceTag_const_Id_FaceTag new2Old ) 
updates existing caches after some faces were split into parts (e.g. by splitFace() or splitEdge()) with no other changes in the mesh;
it shall be considered as a faster alternative to invalidateCaches() and following rebuild of AABB tree
\\param new2Old maps every face appeared after the splits to the face it was split from (as filled by splitFace() and splitEdge());
it must contain only the splits made since the AABB tree was built or last updated: a map accumulated over several updates
would add the earlier faces to the tree once more
