Detailed Description

Members:

  MeshSerializeFormat : file extension (starting with '.') used to serialize ObjectMeshHolder by default, if not overridden in specific object

  PointsSerializeFormat : file extension (starting with '.') used to serialize ObjectPointsHolder by default, if not overridden in specific object;
falls back to PLY if given format is not supported

  VoxelsSerializeFormat : file extension (starting with '.') used to serialize ObjectVoxels by default, if not overridden in specific object

  Count : total count
