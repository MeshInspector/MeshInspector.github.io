Detailed Description

Members:

  Unsigned : unsigned distance, useful for bidirectional `Shell` offset

  OpenVDB : sign detection from OpenVDB library, which is good and fast if input geometry is closed

  ProjectionNormal : the sign is determined based on pseudonormal in closest mesh point (unsafe in case of self-intersections)

  OddCrossings : a point is inside if the surface is crossed an odd number of times on the way from the point to infinity, triangle orientation is ignored
(as InsideMeshRule::OddCrossings in makeInsideMeshVolume); for meshes with holes, the result depends on the ray direction (+X);
signedDistanceToMesh casts a ray from every point, while the volume functions (e.g. meshToDistanceVolume) cast one ray per row of voxels, which is much faster;
this mode does NOT have CUDA acceleration at this moment

  WindingRule : old name of OddCrossings

  HoleWindingRule : computes robust winding number generalization with support of holes and self-intersections in mesh,
it is the slowest sign detection mode, but it CAN be accelerated with CUDA if this mode activated e.g. in OffsetParameters.fwn
