typedef struct MR_AABBTreePoints MR_AABBTreePoints

bounding volume hierarchy of a point cloud with up to 4 children per node in SIMD layout: every internal node keeps the boxes of its children; the points of leaf l are orderedPoints() [MaxNumPointsInLeaf * l, MaxNumPointsInLeaf * ( l + 1 ) ), all leaves are full except the last one Generated from class MR::AABBTreePoints. Supported MR_PassBy modes: MR_PassBy_Move (and MR_PassBy_DefaultArgument and MR_PassBy_NoObject if supported by the callee).
